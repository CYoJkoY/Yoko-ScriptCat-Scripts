# Web Fullscreen Button

![Web Fullscreen Button 图标](./assets/web-fullscreen.svg)

面向全站视频播放器的用户脚本（UserScript）：给只有「全屏」入口的播放器补一个「网页全屏」按钮，插在原生全屏按钮前面。网页全屏只把播放器铺满浏览器视口，不进入系统全屏，也不触发站点的全屏 API。

- 版本：1.0.6
- 许可：MIT
- 运行环境：ScriptCat / Tampermonkey / Violentmonkey 等 UserScript 管理器
- 适用页面：`http://*/*`、`https://*/*`（含 iframe）

## 核心特性

- 为只有原生全屏入口的播放器自动注入「网页全屏」按钮，并保持位置、尺寸与原生控件一致。
- 网页全屏仅把播放器铺满浏览器视口，不调用站点或系统全屏 API。
- 支持动态控制栏、iframe、自定义控制栏与原生 `<video controls>` 浮动回退。
- 进入前快照播放器样式，退出时完整还原，不留下持久样式或站点状态变更。

## 安装

1. 在 ScriptCat / Tampermonkey / Violentmonkey 中新建或导入 UserScript。
2. 安装 `dist/web-fullscreen.user.js`。
3. 打开任意包含视频播放器的页面；已有网页全屏、影院或宽屏入口的播放器不会被重复注入。

## 一、设计目标

- 补缺不覆盖：页面已经有网页全屏、影院、宽屏入口时直接跳过，不重复注入。
- 位置跟随原生控件：新按钮是原生全屏按钮的浅拷贝，样式与控制栏一致，并始终紧贴在它前面。
- 不改站点行为：按钮只切换脚本自己的视口铺满状态，不调用站点的全屏处理器，也不改写播放器的播放状态。
- 可逆：进入时快照全部被改写的内联样式，退出时逐项还原，不在页面上留下永久样式。

## 二、按钮如何找到位置

脚本从每个可见视频向上最多走 12 层，寻找最近的、带有全屏控件的播放器祖先，并在每一层做尺寸约束，避免把页面级「全屏」按钮误认成播放器控件。命中后按控件文本与 `aria-label`、`title`、`data-title` 等属性打分：

- 严格匹配「全屏」「全屏播放」「进入全屏」「Fullscreen」「Enter fullscreen」等标签才作为锚点。
- 只命中 `全屏` 但没有网页全屏语义的控件，才认为该播放器缺这个入口。
- 出现「网页全屏」「Web Fullscreen」「影院」「宽屏」「Theater」等既有入口时整段跳过。

找到锚点后，脚本克隆锚点的标签与样式类，移除 `id`、`href`、`disabled`、`aria-pressed` 以及全部 `data-*` 属性，清掉 `active`、`selected`、`disabled` 一类状态类，再换成自绘的「网页全屏」图标，最后 `insertBefore` 到原生全屏按钮前。因为不带站点的 `data-role`，点击不会被站点的事件委托当成原生全屏。

自定义控制栏的播放器会先等待一次玩家交互（指针移入、按下、触摸或键盘聚焦）再判定并注入：部分站点在悬停后才渲染控制栏，延迟判定可以等到站点自带的网页全屏入口一起出现，避免重复入口闪一下。原生 `<video controls>` 的浮动回退不等待交互，仍然即时可用。

插入后还会根据控制栏的布局方式补位，避免新按钮和原生全屏按钮左侧已有的控件挤在一起：

- `flex` / `inline-flex` / `grid` / `inline-grid` 控制栏：按钮保持自身内容宽度（`flex: 0 0 auto`），不参与压缩；控制栏已有 `column-gap` 时直接沿用，否则左右两侧分别判断——左侧看按钮自身是否已有起始外边距，右侧看原生按钮的前置外边距或按钮自身的结束外边距，缺哪一侧就给哪一侧补 `0.35em`。因为克隆会丢掉 `id` 与 `data-*` 选择器带来的外边距，按钮自身的值按实际计算样式检查，而不假定与原生按钮一致。
- 绝对定位的控制栏：无论克隆按钮当前的定位模式是什么，都先把 `position` 对齐原生按钮（克隆保留共享类规则，可能仍停留在 `relative`，此时只复制偏移会按流内自身位置起算，垂直方向无法靠横向位移修正），再把原生按钮的 `top` / `right` / `bottom` / `left` 计算值同步到新按钮（包括 `auto`，用于清除共享类继承来的冲突约束），然后让按钮向左让出与原生按钮之间的间距，最后把按钮前面的所有 HTML 与 SVG 控件整体向左平移同样距离，保持它们之间的原始间隔。若元素本身已有 `translate`，位移以 `calc(原值 ± 增量)` 叠加而非覆盖；带 `transform` 的元素用其线性矩阵求逆，把屏幕空间的横向位移换算成本地坐标位移——缩放按比例放大，旋转则沿元素自身的轴移动，矩阵接近奇异（缩放过小）时跳过该控件而不是把它甩出去。窗口尺寸变化、断点切换，或原生按钮及其祖先的 `class` / `style` 变化后，一旦原生按钮的布局盒发生变化就重新补位，避免固定像素位移过期。RTL 页面不做这套位移，避免方向判断错误；此时克隆按钮保持共享类规则的流内定位，不会被同步成 `absolute` 而独占覆盖相邻控件，改由 flex/grid 的间距与自然顺序占位。
- `relative` / `sticky` 控制栏：同样先对齐 `position`，再把 `top` / `right` / `bottom` / `left`（包括 `auto`）同步到按钮。这两类定位不会把控件移出文档流，但偏移会直接改变它的视觉位置；只复制 `position` 会让新按钮与原生按钮错开。

按钮同时沿用原生按钮的计算 `box-sizing`：克隆丢掉 `id` 与 `data-*` 选择器后，若原生按钮是显式尺寸的 `content-box`，强写 `border-box` 会让新按钮的外框变小、与相邻控件错位。

按钮与自绘图标的尺寸不再写死 `em`：脚本测量原生全屏按钮自身图标（`svg` / `img` / `i` / 非交互的图标类元素）的渲染尺寸，取不到时改用控制栏内相邻控件的图标尺寸中位数，并复制原生按钮的 `font-size`。图标类名只是线索，`<button class="icon-button">` 这类交互容器不会被当成字形本身，而会回退到相邻图标，避免把 40px 的按钮框写成图标尺寸。`getBoundingClientRect()` 的结果包含元素自身与祖先的 `transform`，而写入克隆图标的宽高是变换前的 CSS 尺寸，因此测量值会先按克隆图标将要继承的完整变换链还原，缩放过的控制栏不会把图标缩小两次；`transform` 简写与独立的 `scale` / `rotate` 属性也一并计入。测得的尺寸写入按钮的 `min-width` / `min-height` 与图标宽高，同时纳入补位快照；窗口尺寸、断点或控件显隐变化后重新测量，避免新按钮比相邻控件小一圈。`ResizeObserver` 观察原生按钮及同一控制栏内的控件与图标，负责网页字体加载等布局尺寸变化；只改变 `transform` 的 `:hover` 规则不改变布局盒，也不会产生可观察的属性变化，因此控制栏上的指针移入/移出、焦点进入/离开以及 `transform` / `scale` / `rotate` 过渡结束都会触发一次防抖重测，指针离开后克隆图标不会停留在悬停尺寸。

## 三、网页全屏的行为

进入时：

- 播放器祖先改为 `position: fixed`、`100vw × 100vh`，清除最大/最小宽高、外边距、内边距、圆角与 `overflow`。
- 视频在自定义播放器内改为铺满父容器、`object-fit: contain`；浏览器原生 `<video controls>` 则直接把视频本身提升到视口。
- 逐层中和 `transform`、`filter`、`perspective`、`contain`、`will-change`、`z-index`、`isolation` 等会造成包含块的祖先，并穿过 Shadow DOM 宿主继续向上处理。
- 锁定 `documentElement` 与 `body` 的滚动，多个视频/多级 iframe 共享同一份引用计数，退出一个不会提前解锁。
- 按钮的 `aria-label` 与 `aria-pressed` 同步为「退出网页全屏」/ `true`。

退出时按快照逆序还原全部内联样式，释放滚动锁。`Esc`、再次点击按钮、或用户进入真正的浏览器全屏都会退出网页全屏。

## 四、动态页面与 iframe

- MutationObserver 监听普通 DOM 与开放的 Shadow DOM；控制栏重渲染后，按钮会被重新插回原生全屏按钮前。
- 扫描做了 180ms 防抖，`ResizeObserver` 负责视频尺寸变化后的重新判断。
- iframe 内只铺满 iframe 本身没有意义，所以子页面通过 `postMessage` 请直接父级把该 iframe 提升到视口；多级嵌套逐层转发，跨域嵌入同样有效，且不读取父页面 DOM。
- 父级在收到 `enter` 时会检查用户激活状态，避免页面脚本伪造消息自动抢占视口。
- 子页面退出、父页面退出、`Esc` 会互相同步，不会出现只退出一半的状态。

## 五、浏览器原生控件的回退

浏览器原生 `<video controls>` 的控制栏位于闭合的 Shadow DOM 内，页面脚本无法插入节点。此时脚本改为在视频右下角、原生全屏图标左侧浮出一个独立的深色按钮，位置随滚动、窗口尺寸和视频位置更新；视频移出视口时自动隐藏。

因此：

- 自定义控制栏的播放器：按钮确实插在原生全屏按钮前面，跟随控制栏样式。
- 浏览器原生控制栏：按钮浮在原生全屏图标附近，无法嵌入控制栏内部。

## 六、已知边界

- 闭合 Shadow DOM 内的自定义控件同样无法插入，会回退为浮动按钮。
- 站点已有网页全屏/影院/宽屏入口时，脚本不介入。
- 全屏状态只作用于当前页面与嵌套 iframe，不进入系统全屏，也不接管浏览器自身的全屏快捷键。
- 播放器若把视频放在 `canvas` 或私有渲染层里，脚本仍会铺满其容器，但不会改写该渲染层的内部尺寸。

## 七、图标与更新记录

用户脚本管理器里显示的图标来自 [docs/assets/web-fullscreen.svg](./assets/web-fullscreen.svg)：浏览器窗口外框、地址栏与四角展开标记组合成「网页内铺满」的语义。构建时内联为单行百分号编码的 `@icon` data URI，不依赖外部图片地址。

### 1.0.1

- 控制栏新增补位逻辑：flex/grid 控制栏保持按钮自然宽度并逐侧补足间隔；绝对定位控制栏先让克隆按钮与原生按钮的 `position` 一致，再同步定位偏移后统一左移前置控件，位移叠加而非覆盖已有的 `translate`，并用元素 `transform` 的逆矩阵把屏幕位移换算成本地位移，旋转控件也不会被推成纵向偏移；前置 `<svg>` 控件同样参与测量与位移。窗口尺寸、断点或按钮祖先的 `class` / `style` 变化后按布局盒重新补位，按钮沿用原生 `box-sizing`。
- 新增 `docs/assets/web-fullscreen.svg`，并在用户脚本头部写入内联 `@icon`。

### 1.0.2

- `position` 同步覆盖全部定位模式：锚点为 `absolute` / `fixed` 时继续走簇位移，`relative` / `sticky` 时同步 `top` / `right` / `bottom` / `left`（包括 `auto`），克隆按钮不会再因共享类与 ID 规则的定位差异跑出控制栏。
- 按钮与图标尺寸改为按实际渲染的原生控件动态推导，控制栏重排、断点切换或图标尺寸变化后重新适配；移除回退样式中写死的 `2em` 宽高。
- 自定义控制栏改为首次交互后再判定并注入：站点懒渲染的网页全屏入口若先出现则完全不注入；已存在的浮动回退会在控制栏出现后自动移入按钮前，原生 `<video controls>` 仍即时回退。

### 1.0.3

- 图标尺寸测量改为先按克隆继承的完整 `transform` 链还原成 CSS 尺寸，缩放控制栏中的图标不再被重复缩放；`transform`、独立 `scale` / `rotate` 与旋转矩阵都纳入换算。
- 安装器用 `ResizeObserver` 观察原生全屏按钮、同一控制栏内的控件及其图标；webfont 加载或悬停规则等只改变控件自身尺寸时也会重新补齐克隆按钮，不必等待窗口、视频或 DOM 变化。
- RTL 的 flex/grid 控制栏中，若原生按钮被 ID 规则设为绝对定位，克隆按钮保持流内定位并保留两侧间距，不再因复制 `absolute` 而覆盖相邻控件。

### 1.0.4

- 克隆按钮的最小尺寸按 `box-sizing` 区分换算：`content-box` 的控件先从实测外框扣掉克隆自身的 padding 与边框，再作为内容盒下限，避免按钮被撑得比原生控件更宽或更高。

### 1.0.5

- 克隆按钮的尺寸改为用完整变换矩阵反解本地宽高，旋转 90° 的控件不再把轴对齐包围盒的 20×40 当成原始尺寸；纯旋转与缩放叠加时也能还原。
- 空控件不再把整个按钮框当图标：图标由伪元素或背景绘制时，尺寸回退到相邻控件的图标中位数。
- 原生回退绑定的播放器里，已存在的控件因 `class` 变化变得可识别时会触发重扫，浮动按钮及时移入控制栏；无关的类名变化不会引起全量扫描。

### 1.0.6

- 仅改变 `transform` 的悬停规则会触发防抖重测：控制栏上的指针与焦点进出、以及 `transform` / `scale` / `rotate` 过渡结束都会重新测量；每个播放器独立防抖，连续经过多个播放器不会互相丢弃重测。
- 图标自身匹配只接受真实字形元素；`icon-button` 一类交互容器即使带 `icon` 类名也不再把整个按钮框当成字形，而是回退到相邻控件的图标尺寸。

### 1.0.0

- 首个版本：注入网页全屏按钮、视口铺满、iframe 联动与原生 `<video controls>` 浮动回退。
