# HeyBox Up

![HeyBox Up 图标](./assets/heybox-up.svg)

面向小黑盒 Web 端的用户脚本（UserScript）：网页收藏列表不显示“插眼”（CY）条目，但主页收藏总数会把它们算进去。本脚本单独拉取插眼收藏，在收藏页把插眼条目补到收藏列表下方，按帖子去重。社区首页（`/app/bbs/home`）移除右栏热门社区等冗余模块，改为定宽卡片信息流，并支持在右侧预览帖子评论；帖子详情页（`/app/bbs/link/*`）把站点原生评论区停靠到右栏，正文按纸张式阅读栏排版，保留原生回复与点赞，并在评论区补充默认/时间/点赞/作者排序。帖子页与评论预览都提供“屏蔽 CY”开关，按接口 `is_cy` 字段过滤插眼评论。顶部导航收敛为首页、社区、收藏、文章四个「SVG + 文本」入口；帖子页纵轴中心左右两侧提供 SVG 上一篇/下一篇箭头，切换走站内路由，不整页刷新。社区页（`/app/topic/link/*`）提供只在该社区内生效的帖子搜索；宽屏社区首页改为左频道、中信息流、右热度三栏工作台。

- 版本：0.4.18
- 许可：MIT
- 运行环境：ScriptCat / Tampermonkey / Violentmonkey 等 UserScript 管理器
- 适用页面：`https://www.xiaoheihe.cn/*`、`https://xiaoheihe.cn/*`

## 一、设计目标

- 只补网页端缺失的插眼列表，不伪造、不改写站点自己的收藏总数。
- 不复刻第三方插件的代码：签名算法在本脚本内独立实现，避免引入额外依赖或许可问题。
- 只读：脚本不提交收藏、不发评论、不点赞，也不改动站点数据；收藏结果只写入本地 `localStorage`。
- 一个帖子只出现一次：接口按评论维度返回，同一帖子的多条插眼按 `link.id` 去重。
- 复用站点原生评论：帖子详情页不重写评论组件，只把站点自己的 `.link-comment` 节点停靠到右栏，排序、回复、点赞、展开楼中楼都由站点处理。
- 信息流评论预览：在社区首页不打开帖子也能读评论，默认收起为右缘竖向标签，点信息流里的评论数字才展开；预览只读，回复与点赞通过“打开帖子”回到原生评论区。
- 统一 CY 过滤：帖子页原生评论区与信息流评论预览共用一个偏好，按接口返回的 `is_cy` 标记隐藏插眼评论；默认不隐藏，用户点“屏蔽 CY”后才生效。
- 连续阅读：帖子页纵轴中心左右两侧常驻 SVG 上一篇/下一篇箭头，优先按信息流里的帖子顺序切换，找不到顺序时回退到页面相关推荐与会话内的浏览记录。
- 社区内搜索：社区页（`/app/topic/link/<topic_id>`）的搜索只在该社区内请求，结果与全站搜索分开，不离开当前页面。
- 桌面工作台：宽屏社区首页不再把单列信息流放大居中，而是复用同一份数据排成左频道、中信息流、右热度三栏；窄屏逐步收起右栏和左栏，保留站点原有信息流。

## 二、数据来源

插眼收藏走评论列表接口，路径 `/bbs/app/profile/bbs/comment/list`，关键参数：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `only_cy` | `1` | 只要插眼记录 |
| `filter_type` | `0` | 不过滤类型 |
| `enable_new_style_collect` | `1` | 新版收藏结构 |
| `userid` / `heybox_id` | Cookie `heybox_id`（回退 `user_heybox_id`） | 当前登录用户 |
| `limit` / `offset` | 20 / 递增 | 分页 |
| `no_more` | `false` | 首页固定值 |

其余基础参数（`os_type=web`、`app=heybox`、`client_type=web`、`version=999.0.4`、`web_version=2.5`、`x_client_type=web`、`x_app=heybox_website`、`x_os_type=Windows`、`device_info=Chrome`）与站点网页端保持一致。

响应判定：`status === "ok"` 时读取 `result` 数组；`no_more === true` 或本页为空即停止翻页。单条记录取以下字段：

- `link.id`：帖子 ID，同时用于去重与跳转 `/app/bbs/link/<id>`。
- `link.title`：标题，空值回退“无标题帖子”。
- `link.thumbs[0]`：缩略图，可缺省。
- `text`：插眼时附带的评论内容。
- `create_at`：时间，按秒处理，兼容毫秒值。
- `comment_type`：`1` 记为“回复”，其余记为“评论”。

请求使用页面内 `fetch`，`credentials: include` 携带登录态。接口对 `https://www.xiaoheihe.cn` 返回 `Access-Control-Allow-Origin` 与 `Access-Control-Allow-Credentials`（实测），因此无需 `GM_xmlhttpRequest`，脚本保持 `@grant none`。

信息流评论预览走帖子评论树接口 `/bbs/app/link/tree`，除同一套基础参数外传 `heybox_id`（Cookie）、`link_id`、`is_first`（首页为 `1`）、`page`（从 1 起）、`index=1`、`limit=20`、`owner_only=0`。站点网页端还会带一个空的 `h_src` 参数，脚本在 `link_id` 前补齐，缺省时更容易触发风控。响应 `status === "ok"` 时读 `result.comments`（按楼层分组的数组，每组 `comment[0]` 为楼，后续为楼中楼）、`result.link.title` 与 `result.link.comment_num`。单条评论取 `user.username`、`user.avatar`（兼容拼写 `avartar`）、`text`（去标签后截断 400 字）、`create_at`、`support_num`（兼容 `support_count`）、`reply_count`（兼容 `sub_comment_num`）、`is_cy`（`1`、`"1"` 或 `true` 视为插眼）。

社区内搜索走通用搜索接口 `/bbs/app/api/general/search/v1`，除同一套基础参数外传 `q`、`search_type=link`、`topic_id`（当前社区 ID）、`offset`、`limit=30`、`is_pull_down=0`；时间筛选非空时追加 `time_range`。响应 `status === "ok"` 时读 `result.items` 与 `result.time_range_list`；空结果提示优先取顶层 `search_not_result_tips`，其次取 `result.search_not_result_tips`。脚本先带 `hkey`、`_time`、`nonce` 请求，失败后回退不带签名的请求，两条都失败才显示错误。

## 三、接口签名

接口要求 `hkey`、`_time`、`nonce` 三个签名参数。脚本内独立实现，全部为纯函数：

1. `time = floor(Date.now() / 1000)`。
2. `nonce = md5(time + Math.random()).toUpperCase()`，32 位十六进制。
3. 路径归一化为 `/a/b/c/`，与 35 字符字母表 `AB45STUVWZEFGJ6CH01D237IXYPQRKLMN89` 一起映射，生成 20 字符种子。
4. 种子取 MD5 后，前 5 位映射为 5 字符主体；末 6 位的字符码经列混合与求和后 `% 100` 得到 2 位校验，组合成 `hkey`。

两个容易写错的细节：

- `xtime` 左移结果不能对 255 取模，服务端算法保留高位；截断会算出不同的校验位。
- 列混合只改写前 4 个字节，但求和必须包含原数组全部 6 个字节，否则校验位偏移。

MD5 覆盖 UTF-8 字节，`md5Hex` 与 Node `crypto` 结果一致。签名只覆盖路径与时间，不覆盖查询参数。

## 四、UI 与交互

- 收藏页 https://xiaoheihe.cn/app/user/favour/content ：脚本把插眼条目挂在收藏列表（.user-favour__list）下方，并跳过页面已渲染的同 ID 帖子。区块使用 Shadow DOM，样式与页面隔离。
- 收藏与文章页右栏：收藏页、文章管理页及文章详情页的右侧只保留二维码、小黑盒加速器、黑盒语音、黑盒工坊与备案信息等推广模块；脚本将这些右栏整体隐藏，并让主列表占满内容区。
- 顶部导航：脚本接管 `.nav-links`，隐藏站点原有的七个文字按钮，改为首页、社区、收藏、文章四个入口，每项为内联 SVG 图标加文本。图标默认在悬停、键盘聚焦与激活时播放轻量动效（房子轻晃、气泡上浮、书签落位、纸张翻角），齿轮设置菜单里的“动态导航图标”可切回静态；系统开启“减少动态效果”时同样保持静态。
- 导航状态：按 `location.pathname` 标记当前入口，社区包含 `/app/bbs/home` 与帖子详情；收藏页同时承载插眼收藏区块。视口 ≤940px 时只显示图标，保留 `aria-label` 与悬停提示。
- 全站主题：导航栏右侧新增主题按钮和齿轮设置按钮。主题菜单只放六套预设：跟随系统、夜航（冷灰深色）、纯黑（OLED 黑底低圆角）、浅色（站点原色）、纸页（暖纸底、衬线标题、细边扁平卡片）、雾青（冷雾底、大圆角、柔和阴影）；齿轮菜单放“首页评论预览”“动态导航图标”两个开关，以及“中栏宽度（占屏幕宽度）”的 40% / 48% / 56% / 64% / 72% 分段按钮。两个菜单各自开关，打开一个会收起另一个，支持 Esc 与点击外部关闭；选中项立即生效并写入本机，当前项用强调色描边标出。
- 深色覆盖：夜航与纯黑共用同一套深色规则，覆盖帖子页正文、原生评论区（排序标签、作者赞、时间、IP、楼中楼展开、嵌套回复块）、回复编辑器、加载动画、个人主页列表底色、消息提示，以及 Element Plus 对话框、抽屉、表格、分页、图片查看器与下拉浮层。站点用伪元素绘制页面底色与帖子分隔条（`html` 根元素、`#app > main > section`、`.hb-bbs-home__feed-splitline`、`.hb-bbs-home__splitline`、`main.list`、`.hb-cpt__moment-list-content`），这些颜色不随 CSS 变量走，需单独覆盖。登录表单保持浅色，避免第三方登录控件失去可读性。
- 版式重做：窗口宽度 ≥1200px 时外层容器为 1360px、居中，两侧留白 24px。社区信息流按屏幕宽度的固定比例居中（默认 56%，可在齿轮设置菜单里调整），帖子之间改成 14px 圆角卡片，卡片内边距 20px、间距 12px，用细边与轻阴影区分条目，悬停只抬升边框与阴影。搜索栏跟随信息流同宽居中，不再比信息流每侧多出一截。
- 信息流排版：卡片标题 17px/1.5、600 字重，正文 15px/1.72，作者行压到 13px；底部互动条用 1px 细线分隔。图片圆角 10px，整体层级靠字号、颜色与留白拉开。

- 卡片显示缩略图、标题、插眼内容、类型与时间，点击在新标签页打开帖子；插眼内容前带蓝灰色（#6f8db3）CY 眼睛图标，字号 14px，最多显示 3 行，悬停可看全文。

- 页面收藏列表的 ID 集合变化时重新比对去重结果，分页或增量渲染后不会残留已出现的帖子。

- 社区首页 https://xiaoheihe.cn/app/bbs/home ：隐藏整个右栏（`.cpt-right-side.right`），热门社区、二维码、App 链接与页脚一并移除；信息流收成 960px 居中阅读栏，话题条也改成同风格卡片。

- 帖子详情 `https://xiaoheihe.cn/app/bbs/link/<id>`：左栏保留帖子正文与原生回复编辑器，右栏 424px 停靠站点自己的 `.link-comment` 评论区；右栏原有的相关推荐与二维码模块隐藏。

- 社区搜索结果为只读列表：标题、两行摘要、作者、时间、赞数与评论数，点击走站内路由进入帖子，组合键与中键保留新标签页打开。

- 桌面工作台只重排现有 DOM：频道来自 `.bbs-home__topic-item`，点击时转发给站点原按钮；热门排行读取已渲染卡片，点击滚动到对应帖子并临时描边，不请求新接口、不伪造榜单。评论预览展开时右栏自动让位给预览侧栏。

- 连读顺序：进入帖子前，脚本把社区信息流中已渲染的帖子 ID 按顺序写入 `sessionStorage`；帖子页按当前 ID 定位前后项。当前帖子不在记录中或已到列表末尾时，“下一篇”回退到页面“相关推荐”的第一条；没有可用顺序时用本次会话的浏览记录提供“上一篇”。
- 评论区留在站点原有 DOM 位置：脚本用 CSS Grid 把帖子内容与 `.link-comment` 排成左右两列，不搬动节点，站点祖先选择器与原生样式继续生效。
- 回复、点赞、展开楼中楼、加载更多仍由站点原生逻辑处理；脚本不克隆、不改写评论数据。
- 评论区顶部新增“排序”工具栏：默认、时间、点赞、作者。排序只写 `style.order`，不改 DOM 顺序；站点重渲染后自动重建工具栏并恢复上次模式。
- 排序工具栏右侧新增“屏蔽 CY”按钮：开启后按 `[data-comment-id]` 匹配接口返回的 `is_cy` 评论，给对应楼层加 `data-heybox-up-cy="1"` 并由 `body.heybox-up-hide-cy` 统一隐藏；按钮显示已屏蔽条数，关闭后立即恢复。
- 视口宽度 ≥1200px 时启用左右双栏；窄屏改为上下布局，评论区排在正文下方，不隐藏评论。
- 信息流评论预览：社区首页右侧常驻一个 Shadow DOM 浮层。开启时直接展开信息流首条帖子的评论，不必先点开帖子，也不发生跳转；面板宽 320px（视口 <1400px 为 288px），离窗口右缘 20px、离顶部 80px、底部留 80px，圆角跟随卡片令牌，投影用 `--heybox-up-shadow-2`。展开时页面使用全宽，桌面栅格只在右侧为面板预留与其实宽相同的轨道，不再额外叠加右内边距；中栏按可用空间收缩并保持居中，面板与信息流之间只保留 24px 级间距。首条帖子只自动打开一次：手动收起后不会再次弹出，点右缘的“评论预览”标签才会重新展开。
- 切换预览对象：点信息流卡片里的评论数字（`.bbs-new-style-bottom__comment`、`.content-list__comment`）即可切换到该帖，页面不跳转。
- 预览开关：齿轮设置菜单里的“首页评论预览”关闭后，浮层 `display: none`、页面右缘不留标签，信息流恢复正常宽度，评论数字恢复站点原生行为（进入帖子）；偏好写入 `localStorage`，刷新后保持。重新开启会立刻带出首条帖子的评论。
- 面板顶部显示帖子标题、评论总数与“已加载 N 条”，正文按楼层列出头像、昵称、相对时间、评论内容、点赞数、回复数与最多两条楼中楼；底部“加载更多”按 20 条翻页，切换帖子会重置分页。
- 面板顶部工具区新增“CY”开关，与帖子页共用同一偏好；开启后过滤已加载的 CY 楼层和楼中楼引用，说明行显示“已屏蔽 N 条 CY”，切换时直接重渲染，不重复请求。
- 收起方式为面板右上角按钮或 Esc，收起后页面右缘保留“评论预览”标签，已加载内容不丢弃，重新展开不重复请求；离开首页或进入 `/app/bbs/link/*` 时浮层隐藏，视口窄于 1200px 时同样不显示。
- 预览只读：不提供回复、点赞与展开楼中楼，需要这些操作时点“打开帖子”进入原生评论区；接口失败时面板显示原因与“打开帖子”入口，不伪造评论。

## 五、存储与缓存

- 缓存键 `heybox-up.cy.v1:<userid>`，值为 `{ savedAt, items }`。
- 有效期 10 分钟；命中缓存直接渲染，过期后重新拉取。
- 点击刷新会跳过缓存重新请求，成功后覆盖缓存；请求失败时保留当前已显示的结果。
- 单次最多 200 条（10 页），达到上限即停止，避免长列表拖慢页面。
- 缓存按用户隔离，切换账号不会读到他人数据；`localStorage` 不可用时仅本次会话生效。
- 主题偏好键 `heybox-up.theme.v1`，取值为 `system`、`dark`、`oled`、`light`、`paper`、`mist`，仅存本机；旧值 `dark`、`light` 继续有效。
- 屏蔽 CY 偏好键 `heybox-up.hideCy.v1`，取值 `1` 或 `0`，默认 `0`（不隐藏）；仅存本机，帖子页与评论预览共用。
- 首页评论预览偏好键 `heybox-up.commentPreview.v1`，取值 `1` 或 `0`，默认 `1`（开启）；仅存本机，由齿轮设置菜单里的开关写入。
- 导航图标偏好键 `heybox-up.navMotion.v1`，取值 `1` 或 `0`，默认 `1`（动态）；仅存本机，由齿轮设置菜单里的“动态导航图标”开关写入。
- 中栏宽度键 `heybox-up.feedWidth.v1`，取值 `40`、`48`、`56`、`64`、`72`（百分比），默认 `56`；仅存本机，由齿轮设置菜单里的宽度分段按钮写入，只改 CSS 变量 `--heybox-up-feed-pct`，不重排 DOM。
- 连读顺序键 `heybox-up.feedOrder.v1` 与浏览记录键 `heybox-up.postTrail.v1`，只写 `sessionStorage`，关闭标签页即清除；插眼区块只响应收藏页 URL 的 `#heybox-up-cy` 锚点。
- 评论区由站点组件自行请求与缓存；脚本不保存评论内容与排序。
- 社区内搜索不写 `localStorage`：关键词、时间筛选与已加载结果只保存在当前页面的内存里，刷新或离开页面即清空。
- 桌面工作台不写存储：频道列表与热门排行每次按当前 DOM 重新计算，不缓存到本机，也不跨页面保留。

## 七、已知限制

- 不改站点收藏总数；该数字由服务端 `bbs_info.favour_num` 计算，脚本只能解释差异，不能修正。
- 收藏页的插眼条目由脚本另插节点，不是站点返回的数据；节点挂在列表容器外，站点分页、排序与计数不受影响。站点改版换容器或类名时插入会失效。
- 单用户上限 200 条；更多插眼需要分页按钮，当前未实现。
- 搜索只覆盖已拉取并缓存的条目，不会额外请求服务端；200 条上限同样作用于搜索范围。
- 接口字段与签名规则由站点控制，改版后可能失效；失效时以“加载失败”提示，不会显示假数据。
- 评论预览只读，不能回复、点赞或展开楼中楼；这些交互只在帖子页的原生评论区提供。
- 预览依赖登录态与 `link/tree` 接口的风控策略：未登录或触发验证码时返回 `show_captcha` 等状态，面板显示失败原因，需要打开帖子查看。
- 预览按楼层分页，楼中楼只取前两条；评论触发入口依赖 `.bbs-new-style-bottom__comment` 与 `.content-list__comment` 类名，站点改版后需同步选择器。
- 悬停切换只在面板展开时生效，鼠标需在卡片上停留 600 毫秒以上；每次切换都会请求一次评论接口，长时间来回划过信息流会累积请求，触发风控时面板显示失败原因。
- 自动预览依赖 `#page-bbs-community .bbs-home__content-list` 容器与其中首个 `a[href*='/app/bbs/link/']` 链接；容器或链接结构变化时不会自动带出评论，需点评论数字手动切换。关闭开关后脚本不拦截评论数字，恢复站点原生跳转。
- 脚本未在真实登录态页面内做过端到端点击验证；DOM 逻辑依赖 Shadow DOM 与 `fetch` 的常规行为。
- 站点 CSP 目前允许内联样式；若收紧到禁止 `style-src` 内联，收藏区块的样式需要改为构造样式表。
- 深色模式基于站点现有类名覆盖，站点改版后可能出现未覆盖的浅色块或正文；反馈时请附页面地址与截图。
- 帖子页与收藏页的部分内容需要登录才能渲染，深色样式按站点样式表选择器覆盖，未在登录态逐页点击验证。
- 宽屏布局只在 ≥1200px 生效，依赖站点 `#app > main`、`section`、`.layout-normal` 与 `#page-bbs-community main.list` 结构；站点改版换容器后需要同步选择器。
- 双栏布局依赖 `.hb-bbs-link__content` 的直接子节点结构；站点改版后需要同步选择器，否则评论区会回到默认位置。
- 排序工具栏挂在 `.link-comment` 内，站点清空该节点时会被移除；MutationObserver 在下一帧重建并恢复选中模式。
- 排序读取已渲染的点赞数、相对时间与用户名；“作者”模式按用户名与帖子作者比对，同名用户会一并排到前面。
- CY 屏蔽依赖 `link/tree` 返回的 `is_cy` 字段与楼层的 `data-comment-id`；站点改版去掉字段或属性后，开关仍可点，但不会命中评论。
- 帖子页只为已渲染但未识别的楼层补拉接口，最多 10 页（200 条）；超过上限的楼层保持原样，不误隐藏。
- 帖子页首次识别会额外请求评论接口；未登录或触发风控时请求失败，评论保持可见，需打开帖子或稍后重试。
- 回复编辑器仍位于帖子正文下方，由站点原生逻辑管理；评论区内的回复按钮会按站点默认行为聚焦该编辑器。
- 社区首页隐藏整个右栏；若后续需要保留右栏中的其他模块，需要改为按模块隐藏。
- 纸页与雾青预设依赖站点现有类名着色，站点改版后可能出现未着色的新容器；深色预设同样按类名覆盖，登录表单始终保留浅色。
- 站点全局 `* { padding: 0; margin: 0; font: ... }` 会覆盖 Shadow DOM 的 `:host` 普通声明，排序栏的 host 样式因此全部加 `!important`；新增 Shadow 组件时需沿用同样写法。
- 站点用 `::before` / `::after` 画卡片底部色带与 1px 分隔线，颜色写死为浅灰；底部色带在所有主题下隐藏，其余分隔线在深色主题逐个覆盖。站点改版新增同类伪元素时需同步补充，否则会再次出现白条。
- 正文内嵌卡片（`com-game-card`、`com-album-card`、`com-award-table-card`、`com-chatroom-card`、`com-league-card`、`com-match-card`、`com-mod-card`、`com-sku-card`、`com-wiki-card`）的底色、描边、文字、药丸底与按钮在站点样式表里写死为浅色，深色主题按这 9 类容器逐组覆盖；站点新增卡片类型时同样会出现未覆盖的浅色块。
- 顶部导航依赖 `.nav .nav-links` 与 `.nav-link` 类名：脚本隐藏原生按钮并插入自己的入口，站点改版换容器后需要同步选择器。隐藏的原生按钮仍留在 DOM 中，站点自己的路由与统计不受影响。
- 导航按地址判断激活项；站点若改用纯前端状态切换而地址不变，激活项可能停在上一页，直到下一次地址变化或导航重建。
- 连读顺序来自进入帖子前已渲染的信息流条目，不额外请求列表接口；未滚动到的后续条目不会进入连读顺序。直接打开帖子或刷新后，顺序记录可能已失效，此时“下一篇”使用页面相关推荐。
- 连读切换优先调用站点 Vue 路由（`#app.__vue_app__.config.globalProperties.$router`）；取不到 router 时退回站点 `<a>` 点击，会退化为整页跳转，功能仍可用但会刷新。
- 社区内搜索依赖 `/app/topic/link/<topic_id>` 路由与 `.topic-link__main`、`.topic-link__filter-row` 结构；站点改版换容器后搜索栏不会挂载或位置改变。
- 社区搜索接口受站点风控影响：未登录或触发验证码时返回非 JSON 或失败状态，面板显示错误，不回退到全站结果；回退请求不带签名，若风控要求签名则仍会失败。
- 社区搜索按接口原始返回条数推进 `offset`，并对已显示的帖子 ID 去重；站点返回重复条目时单页实际新增数可能少于 30。
- 社区搜索不持久化关键词、时间筛选与结果，也不实现站点搜索的 `filter_tag` 分类筛选；刷新后回到社区原生信息流。
